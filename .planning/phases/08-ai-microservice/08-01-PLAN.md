# Phase 8 Plan: Assistive AI Microservice (FastAPI), Zero-DB Isolation & Admin Draft Review

## Objective
Implement an isolated, secondary Python FastAPI microservice (`apps/ai`) providing assistive, stateless AI capabilities (PII screening, OCR text extraction, and deduction-ledger-based narrative summary drafting), integrated into Spring Boot via `ai_drafts` persistence and an Admin review interface, while architecturally enforcing zero DB access and absolute scoring immutability.

---

## Architecture & Isolation Rules
1. **Zero Database Access**: The FastAPI microservice runs in isolation with zero database credentials and no connection to PostgreSQL.
2. **Absolute Scoring Immutability**: AI drafts are persisted in an isolated `ai_drafts` table. Accepting, rejecting, or generating a draft NEVER mutates `analysis_runs`, `analysis_items`, `analysis_ledgers`, or `pilot_locations`.
3. **Graceful Degradation**: Governed by `FEATURE_AI` flag (default `true` or configurable). If the AI service is unreachable, disabled, or times out (>8s), the core platform operates unimpeded.
4. **Internal Token Auth**: Requests between Spring Boot and the AI service require `X-AI-Service-Token`.

## Detailed Task Breakdown

### Task 1: Python FastAPI Microservice (`apps/ai`)
- Create `apps/ai` directory structure:
  - `requirements.txt`: `fastapi`, `uvicorn`, `pydantic`, `pytest`, `httpx`
  - `app/main.py`: FastAPI app with CORS, logging, and token verification middleware.
  - `app/config.py`: Service token and environment settings.
  - `app/services/pii_scrubber.py`: Regex and pattern-based PII screening (Aadhaar, phones, emails).
  - `app/services/ocr_extractor.py`: Assistive OCR text extraction simulation / engine.
  - `app/services/narrative_summarizer.py`: Objective, rule-based narrative generation summarizing deduction ledgers into diagnostic executive paragraphs with interventions.
  - `app/services/observation_grouper.py`: Thematic grouping of audit observations.
  - Endpoints:
    - `GET /health`: Liveness probe.
    - `POST /v1/pii-screen`: Detects PII and returns masked text.
    - `POST /v1/extract-text`: Extracts text from evidence documents.
    - `POST /v1/summarise-run`: Generates objective draft summaries from deduction ledger JSON.
    - `POST /v1/group-observations`: Thematic observation clustering.
  - `tests/test_ai_service.py`: Automated tests for token validation, PII screening, and narrative generation.

### Task 2: Database Migration `V7__ai_drafts.sql`

### Task 3: Spring Boot Entity, Repository & AI Client (`apps/api`)
- Entity: `org.abhisaran.ai.persistence.AiDraft`
- Repository: `org.abhisaran.ai.AiDraftRepository`
- DTOs: `AiDraftDTO`, `AiSummariseRequest`, `AiSummariseResponse`, `AiExtractTextRequest`, `AiExtractTextResponse`
- Client: `org.abhisaran.ai.AiServiceClient` (uses `RestTemplate` or `WebClient` with 8s connect/read timeouts, `X-AI-Service-Token`, and fallback).
- Service: `org.abhisaran.ai.AiDraftService`:
  - `generateRunSummary(runId, actorId)`: Reads deduction ledger from DB, calls `AiServiceClient`, saves `AiDraft` with status `DRAFT`.
  - `getDrafts(targetType, targetId)`: Retrieves drafts for an object.
  - `acceptDraft(draftId, actorId)`: Transitions to `ACCEPTED`.
  - `rejectDraft(draftId, actorId)`: Transitions to `REJECTED`.
- Controller: `org.abhisaran.ai.AiDraftController`:
  - `POST /api/v1/ai/summarise-run/{runId}`
  - `GET /api/v1/ai/drafts/{targetType}/{targetId}`
  - `POST /api/v1/ai/drafts/{id}/accept`
  - `POST /api/v1/ai/drafts/{id}/reject`
  - Secured with `@PreAuthorize("hasRole('ADMIN')")`.

### Task 4: Spring Boot Integration Tests
