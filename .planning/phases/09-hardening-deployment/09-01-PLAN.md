# Phase 9 Plan: Hardening, E2E Playwright Testing & Production Deployment

## Objective
Finalize the production readiness of the Abhisaran Platform by implementing:
1. Multi-stage, security-hardened Dockerfiles (`api`, `web`, `ai`) and updated `docker-compose.yml`.
2. Production deployment specification (`render.yaml`).
3. Complete Playwright End-to-End test suite (`e2e/`) validating the entire platform lifecycle per Section 16.
4. Comprehensive Security Hardening Review (`docs/SECURITY_AUDIT.md`) assessing OWASP Top 10 and ASVS Level 1 compliance.
5. Operational Runbook & Disaster Recovery documentation (`docs/OPERATIONS_RUNBOOK.md`).

---

## Detailed Task Breakdown

### Task 1: Multi-Stage Production Dockerfiles & Nginx Config
- **`apps/api/Dockerfile`**:
  - Multi-stage build with Maven (`eclipse-temurin:21-jdk-alpine` builder) and slim JRE runtime.
  - Non-root user `abhisaran` (UID 10001).
  - Healthcheck hitting `/actuator/health`.
  - Spring environment bindings (`PORT=${PORT:-8080}`).
- **`apps/ai/Dockerfile`**:
  - Python 3.11-slim base image.
  - Non-root user `aiuser`.
  - Installs dependencies from `requirements.txt`.
  - Runs `uvicorn app.main:app --host 0.0.0.0 --port 8000`.
- **`apps/web/Dockerfile` & `apps/web/nginx.conf`**:
  - Stage 1: Node 20-alpine builder (`npm run build`).
  - Stage 2: Nginx unprivileged Alpine runtime.
  - `nginx.conf`: SPA routing (`try_files $uri /index.html`), reverse proxy `/api/` to backend, security headers (CSP, HSTS, X-Content-Type-Options: nosniff, X-Frame-Options: DENY, Referrer-Policy).
- **`docker-compose.yml`**:
  - Verified local multi-service orchestration with healthy dependency chains.

### Task 2: Production Cloud Deployment Spec (`render.yaml`)
- Infrastructure-as-Code manifest for Render deployment:
  - Managed PostgreSQL instance (`abhisaran-db`).
  - Spring Boot Web Service (`abhisaran-api`) with healthcheck and environment secrets.
  - Python FastAPI Private Service (`abhisaran-ai`) with internal token auth.
  - Static or Docker Web Service (`abhisaran-web`) with custom Nginx proxying.
  - Documented cold-start tolerances and connection pooling limits.

### Task 3: Playwright End-to-End Test Suite (`e2e/`)
- Setup Playwright in `e2e/` or root:
  - Test scenario 1: Splash screen animation → Admin login (`admin` / password).
  - Test scenario 2: Location creation (`create location` generating immutable code `JH-RCH-SCH-xxxx`).
  - Test scenario 3: Field audit workspace (Page 1 & Page 2, multi-page data entry, evidence magic-byte upload, PII detection testing).
  - Test scenario 4: Submission & Deterministic Scoring analysis (`POST /analyse`), verifying deduction waterfall and mathematical balance.
  - Test scenario 5: Jurisdictional Visibility & Officer Isolation:
    - Officer A (assigned matching district) logs in, sees the ACS run in inbox, opens details and evidence.
    - Officer B (assigned other district) logs in, inbox is strictly empty (zero PII, zero cross-district leakage).
  - Test scenario 6: Admin AI Narrative Assistant (generating draft, accepting draft, asserting ACS immutability).
- Playwright config supporting headless execution and cross-browser coverage.

### Task 4: Security Hardening Review (`docs/SECURITY_AUDIT.md`)
- Detailed verification against:
  - OWASP Top 10 (Injection, Broken Auth, Sensitive Data Exposure, XML/XXE, Broken Access Control, Security Misconfiguration, XSS, Insecure Deserialization, Vulnerable Components, Insufficient Logging).
  - Anti-PII guarantees (server-side Aadhaar, phone, email blocking).
  - Immutability and audit logging (append-only PostgreSQL design).
  - Cryptographic secret generation and storage (Argon2id, HMAC-SHA256, magic-byte checks).

### Task 5: Operations Runbook & Backup/Restore Guide (`docs/OPERATIONS_RUNBOOK.md`)
- Cold start mitigation guide for free/hobby tiers.
- PostgreSQL automated backup (`pg_dump`) and point-in-time restore procedure.
- Secret rotation manual (JWT, DB, AI token).
- Audit log forensics and incident response playbooks.

### Task 6: Final Verification & Phase 9 Summary
- Execute all test suites (unit, golden vectors, integration, AI pytest, and build verification).
- Compile Phase 9 Summary and update `ROADMAP.md` and `STATE.md`.
