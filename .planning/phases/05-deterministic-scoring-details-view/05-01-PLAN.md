# Phase 5 Plan: Deterministic Scoring Engine & Analysis View

## Objective
Implement multi-page pooled scoring across submitted audit pages, generate the mathematically balanced Deduction Ledger, persist immutable analysis runs in PostgreSQL, verify against shared golden vectors, and deliver the rich Decision-Support Analysis Details View.

### Task 2: Shared Golden Test Vectors & Pure Pooled Evaluator
- Add `shared/golden-vectors/*.json`:
  1. `canonical_4page_audit.json`: Matches Section 7 worked example (ACS = 90.00, Ledger sum = 10.00).
  2. `perfect_score_audit.json`: All questions answered fully (ACS = 100.00, Ledger sum = 0.00).
  3. `severe_critical_gaps_audit.json`: Critical questions < 50% earned triggering Section 9.5 clamp to RED (ACS < 40.00).
  4. `provisional_low_coverage_audit.json`: Coverage < 70% badged PROVISIONAL.
  5. `zero_denominator_unassessed_audit.json`: Questions with 0 denominator excluded, non-calculable fallback.
- Extend `ScoringEngine` with `evaluateLocationAudit(LocationAssessmentInput)`:
  - Multi-page pooled score computation:
    $$\text{ACS} = \left(\frac{\sum \text{earned\_w}}{\sum \text{max\_w}}\right) \times 100$$
  - Deduction ledger generation:
    $$\text{loss\_contribution}_{p,i} = \left(\frac{\text{lost\_w}_{p,i}}{\sum \text{max\_w}}\right) \times 100$$
  - Mathematical balance assertion: `|sum(loss_contribution) - (100.0 - ACS)| < 0.001`.
- Comprehensive JUnit test suite: `ScoringEngineGoldenVectorTest.java`.

### Task 3: Backend Entities, Repositories, Service & Controllers
- JPA Entities: `AnalysisRun`, `AnalysisItem`, `AnalysisLedgerEntry`.
- Repositories: `AnalysisRunRepository`, `AnalysisItemRepository`, `AnalysisLedgerRepository`.
- DTOs: `AnalysisRunDTO`, `AnalysisItemDTO`, `DeductionLedgerDTO`, `SectionScoreDTO`.
- `AnalysisService`:
  - Fetches submitted pages & answers for a location.
  - Invokes pure `ScoringEngine` to compute ACS, items, and ledger.
  - Persists run, items, and ledger in a single atomic transaction.
  - Emits immutable audit log entry.
- `AnalysisController`:
  - `POST /api/v1/locations/{locationId}/analyse`: Trigger analysis.
  - `GET /api/v1/locations/{locationId}/analysis/latest`: Get latest analysis for a location.
  - `GET /api/v1/analysis/{runId}`: Get specific run.
- Integration Test: `AnalysisIntegrationTest.java`.
