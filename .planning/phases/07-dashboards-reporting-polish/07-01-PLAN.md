# Phase 7 Plan: Administrative Dashboards, Bulk Analyse, Code-Only PDF Reports & Security Audit Log

## Objective
Deliver Phase 7 in strict conformance with `ANTIGRAVITY_PROMPT_AUDIT_PLATFORM.md` (Sections 10, 11, 13) and `docs/ROADMAP.md`:
1. Administrative Overview Dashboard with summary tiles, dependent geographic filters, and multi-facility oversight.
2. Strict non-ranking enforcement: default sorting by permanent facility code, zero leaderboards, zero top/bottom rank columns.
3. Bulk Analyse execution with real-time `<AbhisaranLoader />` progression and automatic atomic delivery to district officers.
4. Code-Only printable PDF Report generator for ACS scores, deduction ledgers, and section breakdowns with zero PII or institution names.
5. Append-only Security Audit Log Viewer with filtering by action, actor, and timestamp.
6. Full accessibility compliance (WCAG 2.1 AA) and responsive polish.

---

## Tasks

### Task 1: Backend Endpoints & Services
- **Dashboard Overview API (`GET /api/v1/dashboard/overview`)**:
  - DTOs: `DashboardOverviewDTO`, `LocationOverviewItemDTO`, `DashboardMetricsDTO`.
  - Service query: Enriches pilot locations with page counts, latest `AnalysisRun` summary (ACS score, alert band, coverage %, provisional flag, analyzed at), and status.
  - Implements status counter metrics (`totalLocations`, `readyForAnalysisCount`, `analysedCount`, `draftCount`, `registeredCount`).
  - Guarantees default sort by `code ASC` (strict non-ranking enforcement).
- **Bulk Analyse API (`POST /api/v1/locations/bulk-analyse`)**:
  - DTOs: `BulkAnalyseRequest` (`locationIds: List<UUID>`), `BulkAnalyseResponse`, `BulkAnalyseItemResult`.
  - Service: Processes each eligible location through `AnalysisService.analyseLocation`, ensuring atomic scoring and officer delivery per location.
  - Returns count of requested, succeeded, and failed runs with per-item details.
  - Logs `BULK_ANALYSE` action in `AuditLogService`.
- **Security Audit Log API (`GET /api/v1/audit-log`)**:
  - `AuditLogController` (`@PreAuthorize("hasRole('ADMIN')")`).
  - DTO: `AuditLogEntryDTO`.
  - Supports pagination (`Pageable`) and filtering by `action`, `actorRole`, and `objectType`.
